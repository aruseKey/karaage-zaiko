# 唐揚げ在庫管理

匠の金賞唐揚げの在庫（購入・分配・回収）を記録して、みんなで共有するアプリです。

- だれでもログインなしで記録・閲覧できます。
- 住所だけは、パスワードを入れたときに表示されます。新しく預ける家の住所の登録・変更も、同じパスワードを入れた人だけができます。
- スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

公開URL（GitHub Pages）：https://arusekey.github.io/karaage-zaiko/

## しくみ

| 部分 | 置き場所 |
|---|---|
| 画面 | このリポジトリ（GitHub Pages で公開） |
| データ | Googleスプレッドシート「唐揚げ在庫管理データ」（春瀬のGoogleドライブ） |
| API | スプレッドシートに紐づけた Apps Script（`apps-script/Code.gs`） |

スプレッドシートのタブ：

- **家**：名前・11/1時点の袋数・住所・メモ・今の袋数（数式）
- **記録**：アプリから入った購入・分配・回収（取り消すと「取消日時」が入る）
- **設定**：基準日・基準の手元・未分配、合計の数式
- **メモ**：在庫タブに出す「数の確認メモ」

## 最初の準備（1回だけ）

1. スプレッドシート「唐揚げ在庫管理データ」を開き、**拡張機能 → Apps Script**
2. 最初からある `Code.gs` の中身を全部消して、`apps-script/Code.gs` の中身を貼り付けて保存
3. 左の歯車（プロジェクトの設定）→ 一番下の **スクリプト プロパティを追加**
   - プロパティ：`ADDR_PASSWORD`
   - 値：住所を見るためのパスワード
4. 右上の **デプロイ → 新しいデプロイ** → 種類の選択（歯車）で **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - デプロイ → アクセスを承認（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を `config.js` に入れてコミット

## Apps Script を直したとき

**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ**。URLは変わりません。

## データを直したいとき

- 住所は、アプリの「住所を見る」→「住所を登録・変更する」から直せる
- 基準の袋数・メモは、スプレッドシートの「家」「メモ」タブを直接直す
- 記録の間違いは、アプリの「取り消す」を2回押す

## 注意

このリポジトリは公開されています。住所やパスワードは、このリポジトリに書かないでください。
